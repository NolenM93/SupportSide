Conway's Game of Life

An interactive desktop simulator of John Conway's cellular automaton. Click cells, watch generations evolve, switch between finite and wrap-around grids. Built to develop skills in code organization, testing, and UI design.

School Project Open Source

About the Project

Conway's Game of Life is a zero-player game where cells on a grid live, die, or reproduce based on simple rules. It's a classic example of how complex patterns can emerge from simple rules—a concept that's relevant to everything from biology to computer science.

I built this as a school project to practice designing, organizing, and testing code. The focus wasn't just on making it work, but on making it maintainable: clean separation between the simulation logic and the UI, proper state management, and code that's easy to extend.

Features

Interactive Grid

Click cells to toggle them alive or dead.

Generation Playback

Play, pause, and step through generations.

Boundary Modes

Finite grid or toroidal wrap-around.

Live Statistics

HUD shows living cells and neighbor counts.

The Rules

  • 1 A live cell with 2 or 3 neighbors survives.
  • 2 A dead cell with exactly 3 neighbors becomes alive.
  • 3 All other cells die (or stay dead).
