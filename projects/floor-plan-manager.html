Floor Plan Manager

A floor plan management tool built for banquet operations. Place tables on a drag-and-drop canvas, assign server teams, generate service passes, and manage the setup for events from cocktail hour to dinner.

Live Demo Open Source

The Problem

Hotel banquet operations juggle multiple events, each with different floor plans, table assignments, and server teams. The traditional approach—paper diagrams, spreadsheets, and radio calls—doesn't scale when you have back-to-back events and a room that needs to flip from cocktails to dinner in 30 minutes.

Banquet captains need to see the floor, assign tables to teams, and print service passes that servers can actually use. Operations needs to know what moves and when.

Key Features

Canvas Floor Plan

Drag and drop tables with snap-to-grid alignment.

Team Management

Create server teams and assign tables by color.

Service Passes

Print ready-to-use assignment sheets for each team.

TV View

Display-ready view for wall-mounted screens in the service area.

How It Works

  1. 1 Create an event. Give it a name, date, and expected cover count.
  2. 2 Add tables. Place rounds, rectangles, or custom shapes. Snap to grid or free-place.
  3. 3 Assign teams. Create color-coded server teams and drag tables into their sections.
  4. 4 Print and display. Generate service passes for staff or push to the TV view.
