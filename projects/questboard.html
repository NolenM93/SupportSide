Team Project · Cross-Platform App

QuestBoard

A gamified team progress tracker that transforms everyday tasks into engaging quests. Built with Flutter for cross-platform deployment. I handled the Firebase backend: authentication, real-time progress sync, and cloud storage.

Live Demo Open Source

The Concept

QuestBoard turns team productivity into an adventure. Instead of checking off tasks on a boring list, team members complete "quests" that earn XP, unlock achievements, and level up their mascot companions.

Built for student development teams, remote startups, hackathon squads, and any group that wants to make work feel more engaging. The gamification isn't gimmicky—it's designed around real behavioral psychology research on motivation and habit formation.

Key Features

Quest System

Transform tasks into quests with XP, difficulty tiers, and dependencies.

Achievement Badges

Tiered badges from Bronze to Diamond across multiple categories.

Mascot Companions

Virtual pets that evolve as your team levels up.

Progress Visualization

Journey maps, sprint tracking, and real-time XP calculations.

My Role

I handled the Firebase backend for the team. That meant setting up:

  • Authentication — User sign-up, login, and session management
  • Real-time sync — Live progress updates across all team members
  • Cloud storage — Quest data, achievements, and user profiles
  • Database architecture — Structured data for quests, teams, and mascots
